# Coding standards

Rules for review that no check can enforce. Mechanical rules live in `scripts/check.sh`.

- A change to what the user sees or does in a window (cheat sheet, settings, menu bar) updates
  the matching part of `docs/guide.md` in the same commit: the Config section for the
  settings window and the menu bar title (`titleFormat`, `layerWidth`), the cheat sheet
  description for the popover.
